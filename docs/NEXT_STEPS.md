Further work is optional and should begin with its own threat model and acceptance criteria:

1. **Isolated ORAM timing replication completed for two- and eight-address workloads; wider workload scope remains.** Both 30-trial studies passed plaintext/encrypt-only positive controls. The follow-up eight-address hot/cold AUC was 0.507 [0.496, 0.517] under local bucket-handler timing; see [eight-address method/results](ORAM_EIGHT_ADDRESS.md) and [raw-hash verified output](../experiments/results/oram-isolated-eight-address-20261024/). The initial unpaired two-address run is explicitly superseded. Extend to additional operation mixes, address distributions, and attacker families; neither near-chance result is a security proof.
2. **Synthetic presence sensitivity completed:** eight scenarios test noisy semantic beacons, enrollment churn, missed cover observations, and changing populations over 240 sessions/scenario. The combined adverse synthetic case still enabled 79.4% owner recovery (95% whole-session bootstrap interval 73.3–85.0%) against 11.5% population-adjusted random accuracy. This is not real network evidence or differential privacy; see [the study](PRESENCE_SENSITIVITY.md). Real-network validation remains future work.
3. **Bounded human-query corpus evaluation completed:** the pinned MIMICS-Click query text drove the existing constrained-GGM SSE evaluator over 30 whole-query split trials. Exact-count and unpadded positive controls succeeded; public-bound padding reduced the count-volume attack to profile-majority levels on the 12.2%-coverage subset. See [corpus study and terms](HUMAN_QUERY_EVALUATION.md) and [aggregate output](../experiments/results/human-query-20261024/). MIMICS has no query arrival frequencies or temporal histories, its README has ambiguous licensing language, and this result is not representative of Bing traffic. Broader licensed trace access/query-prior drift remains open.
4. **Local batcher population sweep completed; deployment capacity/cost remain open.** The 30-trial component study covers 100 epochs at populations 1/8/32/64; frame rate scales from 40 to 2,560 frames/s while p95 epoch queue wait stays around 23.6–23.7 ms. See [report and scope](POPULATION_SWEEP.md). Clients share one local host and the full WASM/ORAM path is not exercised. Longer full-platform steady-state load, external interfaces, and provider-calibrated costs still need deployment resources.
5. Evaluate actual TEE/attestation and hardware side channels, formal DP adjacency/sensitivity/composition, recursive maps/native Circuit storage, DPF/native single-server runtime selection, and real worker-pool provisioning if those extensions are selected.
6. Design persistent/backward-private SSE, independently protected checkpoint-anchor publication, acknowledgment/side-effect ordering and dynamic registry signing/version policy before persistent application deployment.

The deterministic built-in demo remains a correctness/topology exercise.
