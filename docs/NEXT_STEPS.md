The combined adverse synthetic case still enabled 79.4% owner recovery (95% whole-session bootstrap interval 73.3–85.0%) against 11.5% population-adjusted random accuracy. This is not real network evidence or differential privacy; see [the study](PRESENCE_SENSITIVITY.md). 3. **Bounded human-query corpus evaluation completed:** the pinned MIMICS-Click query text drove the existing constrained-GGM SSE evaluator over 30 whole-query split trials. Exact-count and unpadded positive controls succeeded; public-bound padding reduced the count-volume attack to profile-majority levels on the 12.2%-coverage subset. 4. **Local batcher and full-path offer studies completed; deployment capacity/cost remain open.** The component sweep covers 100 epochs at populations 1/8/32/64. Full-path studies include 64 offers and a preregistered extension with 128 offers at 150 ms and 256 offers at 25 ms, each over 30 fresh processes/profile with actual PIR/WASM/ORAM work. The 128-offer schedule admitted all offers; the 256-offer schedule dropped 74.22% and missed the offered-load SLO for 99.22%. A ratio-of-sums CPU normalization and whole-process bootstrap sensitivity now use the retained 128/256-offer data; the overloaded profile's lower CPU per success reflects dropped offers and its 99.22% SLO failure, not better useful capacity. See [batcher results](POPULATION_SWEEP.md), [64-offer results](RUNTIME_POPULATION.md), [extended-offer results](RUNTIME_POPULATION_EXTENDED.md), and [CPU cost sensitivity](COST_SENSITIVITY.md). These are single-host, single-producer schedules, not remote capacity, multi-host population, long-term traffic tails, or provider-calibrated costs. Those remain open.
5. **Request-level and bounded-user autoscaler samplers implemented conditionally:** the finite-rational capped geometric mechanism reports a composed `(epsilon, delta)` bound for the fixed-horizon count/event observer under independent hidden uniform bits. Exact-rational tests enumerate the capped one-function request-level distribution for three parameter sets and all nonnegative pool shifts up to the user cap in three bounded-user parameter sets. These checks support the per-release bounds for those settings, but do not prove the coupling bound or composition for arbitrary parameters. A source-level sampler review found and fixed boolean acceptance in numeric configuration fields; it did not find a discrepancy in the reviewed sampler path. See [the sampler audit](SAMPLER_AUDIT.md). External cryptographic review, authenticated identity integration, accounting across sessions/deployments, and a complete runtime transcript remain. Optional per-user clipping requires stable non-spoofable IDs and caps the included scaling count across one horizon; the simulator does not authenticate identities, and the 30-trial synthetic cap-2 study shows higher simulated instance-seconds. Public-seed artifacts have no DP guarantee. A predeclared CSPRNG policy-interval attack passed all 28 naive controls; its interval features did not reliably improve paired protected accuracy, though four unadjusted protected results were above chance for hot-pool inference. See [the attack study](AUTOSCALER_INTERVAL_ATTACK.md). A fresh 30-trial OS-CSPRNG likelihood study passed all seven clear-count controls; the particle-filter attack scored 0.525–0.717 balanced accuracy over the tested workload/task cells, with four of seven unadjusted intervals above chance. See [the likelihood study](AUTOSCALER_LIKELIHOOD.md). This is workload-inference evidence, not a DP audit or privacy proof. Actual TEE/attestation and hardware side channels require supported hardware; recursive maps/native Circuit storage, DPF/native single-server runtime selection, and real worker-pool provisioning remain extensions.
6. Runtime signed-registry/PIR integration carries verified 160-byte Ed25519 records through both local secure-PIR workers, with bounded database bootstrap and per-query exact pin checks. Workers verify an externally provisioned publisher-signed catalog against a pinned public key before readiness; optionally, `OBLIVION_REGISTRY_ANCHOR_SOCKET` activates its version and digest in the local SQLite anchor, rejecting rollback/equivocation before PIR startup. The development fallback signer remains ephemeral, and location digests are synthetic. The wire-v2 worker verifies a signed invocation ID and canonical request digest, can restore the latest checkpoint when configured with `OBLIVION_ANCHOR_SOCKET` and `OBLIVION_ANCHOR_STATE_DIR`, looks up receipts before execution, returns saved responses through a reserved dummy path, and atomically commits response/checkpoint on a new signed request. A same-host per-slot advisory lock now allows one cooperating durable worker before checkpoint restore/readiness; raw protocol/database callers and separate hosts can bypass it. The worker restart test verifies response replay, recovered state and same-ID/different-digest rejection. The anchor service still uses an OS permission boundary on one host; restoring an old SQLite backup defeats both catalog and invocation freshness, and there is no hardware anti-rollback source or remote authenticated transport. Arbitrary external side effects are not atomic. Built-in clients use ephemeral per-run keys and IDs, so applications must persist client keys/IDs for reconnect retries. Durable mode performs visible full-tree snapshot work on misses, skips checkpoint creation on receipt hits, and retains only the anchor-current snapshot after successful commits/startup recovery; a crash after publication can leave obsolete encrypted files until the next startup. Host-root inspection, authenticated publisher-key provisioning, remote publication, partial-catalog inclusion proofs, persistent/backward-private SSE, and production deployment remain open.

The deterministic built-in demo remains a correctness/topology exercise. Its code/configuration can reveal the entire real/dummy/function schedule; encryption cannot conceal an identity already fixed by auxiliary knowledge. Experimental workload seeds/truth are separate private driver inputs under the declared attacker contracts, while mechanism parameters remain public. Accepted bounded experiments do not establish global indistinguishability or production security.
