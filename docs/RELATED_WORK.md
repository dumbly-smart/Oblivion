# Related work and construction choices

Primary references checked on 21 October 2026. Dates below identify the linked version/proceedings, not a claim to have reproduced its complete evaluation. DOI strings are included only when verified in the primary artifact. The supplied roadmap's broader bibliography remains useful reading; unverified entries are not promoted to verified citations here.

| Work | Verified primary reference | Relationship to Oblivion |
| --- | --- | --- |
| Path ORAM | Stefanov et al., *Path ORAM: An Extremely Simple Oblivious RAM Protocol*, [author preprint v3, 2014](https://arxiv.org/abs/1202.5150v3), arXiv:1202.5150; arXiv DOI [10.48550/arXiv.1202.5150](https://doi.org/10.48550/arXiv.1202.5150) | Full path access and remapping provide the storage construction. Oblivion adds explicit bucket AEAD and trusted versions; its controller is not constant-time and its position map is nonrecursive. The preprint date differs from the roadmap's conference/journal editions |
| Circuit ORAM | Wang, Chan and Shi, *Circuit ORAM: On Tightness of the Goldreich-Ostrovsky Lower Bound*, [IACR ePrint 2014/672](https://eprint.iacr.org/2014/672) | Optimizes circuit-oriented oblivious storage; a possible future comparison, not the implemented eviction algorithm. The linked archive was received in 2014 and revised later |
| Constrained-primitive SSE | Bost, Minaud and Ohrimenko, *Forward and Backward Private Searchable Encryption from Constrained Cryptographic Primitives*, CCS 2017, [conference-hosted paper](https://acmccs.github.io/papers/p1465-bostA.pdf), DOI [10.1145/3133956.3133980](https://doi.org/10.1145/3133956.3133980) | Diana motivates constrained GGM prefixes; Janus motivates a separate backward-private design. The bounded ephemeral implementation is Diana-inspired and does not inherit the paper's theorem |
| SimplePIR/DoublePIR | Henzinger, Hong, Corrigan-Gibbs, Meiklejohn and Vaikuntanathan, *One Server for the Price of Two: Simple and Fast Single-Server Private Information Retrieval*, USENIX Security 2023, [proceedings page](https://www.usenix.org/conference/usenixsecurity23/presentation/henzinger) | The adapter executes the genuine pinned reference and its real preprocessing. LWE trust and offline hints differ from non-colluding XOR servers; local eight-byte results do not reproduce large-database paper throughput |
| Search-pattern inference | Oya and Kerschbaum, *Hiding the Access Pattern is Not Enough: Exploiting Search Pattern Leakage in Searchable Encryption*, USENIX Security 2021, [proceedings page](https://www.usenix.org/conference/usenixsecurity21/presentation/oya) | Motivates evaluating query equality after volume padding. The local rank attacker is simpler than the paper's maximum-likelihood method |
| IHOP | Oya and Kerschbaum, *IHOP: Improved Statistical Query Recovery against Searchable Symmetric Encryption through Quadratic Optimization*, USENIX Security 2022, [proceedings page](https://www.usenix.org/conference/usenixsecurity22/presentation/oya) | Uses quadratic optimization and iterated assignments. Oblivion's count/frequency baselines do not implement these steps; IHOP remains an explicit attack extension |
| Pancake | Grubbs et al., *Pancake: Frequency Smoothing for Encrypted Data Stores*, USENIX Security 2020, [proceedings page](https://www.usenix.org/conference/usenixsecurity20/presentation/grubbs) | Studies frequency smoothing rather than the prototype's fixed working-set schedule. Its throughput comparisons concern its own systems/workloads and are not local Oblivion measurements |
| Vuvuzela | van den Hooff, Lazar, Zaharia and Zeldovich, *Vuvuzela: Scalable Private Messaging Resistant to Traffic Analysis*, SOSP 2015, [author paper](https://people.csail.mit.edu/dtl/pdf/lazar-vuvuzela.pdf), DOI [10.1145/2815400.2815417](https://doi.org/10.1145/2815400.2815417) | Motivates rounds/cover and explicit trust assumptions. Oblivion uses fixed-rate engineering cover without importing Vuvuzela's mixing or DP guarantee |
| Snoopy | Dauterman et al., *Snoopy: Surpassing the Scalability Bottleneck of Oblivious Storage*, SOSP 2021, [official proceedings listing](https://www.sigops.org/s/conferences/sosp/2021/toc.html), [author artifact](https://github.com/ucbrise/snoopy) | Establishes a systems comparison point for scalable oblivious storage. Oblivion does not reproduce its distributed sharding/provisioning design |

## Attribution and interpretation

The genuine SimplePIR source is pinned and its MIT license preserved in `research/pir_reference/UPSTREAM_LICENSE`. OpenSSE is an architectural/construction reference with AGPL licensing; its code is not copied or translated into the MIT workspace. Verified construction choices and links are detailed in [SSE_DESIGN.md](SSE_DESIGN.md) and [SIMPLEPIR_REFERENCE.md](SIMPLEPIR_REFERENCE.md).

The reviewed material explains why address protection, forward privacy and response padding leave different residual channels. It does not establish that these layers compose automatically. The current system makes its own bounded trust and observation assumptions and tests them empirically. The autoscaler is explicitly a local simulation study rather than a reproduction of a canonical privacy-aware serverless autoscaler paper.

The roadmap's initial uncertainty about public IHOP code is historical: [the author artifact](https://github.com/simon-oya/USENIX22-ihop-code) is now referenced by the SSE experiment documentation. It was not imported. External datasets, current venues/courses and broader survey claims require their own source/license verification before use.
